# Встановлення Home Craft Guilds

## Сервер

1. Збери jar командою:

```bat
gradlew.bat clean buildNeoForge --no-daemon
```

2. Скопіюй jar з `build/libs/` у папку `mods` сервера.
3. Запусти сервер один раз, щоб створився `config/homecraft-guild.properties`.
4. Перевір налаштування, особливо NPC, ліміти територій, големів і інтеграції.
5. Перезапусти сервер.

## Клієнт

Клієнту потрібен цей addon, якщо потрібні:

- guild UI;
- NPC admin/trader UI;
- 3D preview NPC;
- клієнтські межі територій;
- підписи власників ліжок;
- клієнтські косметичні ефекти.

Без клієнтської частини серверна логіка все одно працює, але UI та клієнтські візуальні елементи будуть недоступні.

## Перевірка після встановлення

```mcfunction
/homecraftguild npc
/homecraftguild accept
```

Після першого запуску в логах має бути рядок з `Home Craft Guild integrations`, де видно режим автономності та знайдені optional-модулі.
